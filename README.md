# Лабораторная работа №1: восстановление проницаемости по уравнениям Максвелла

Восстановление относительной диэлектрической проницаемости среды по
электрическому и магнитному полям в трёхмерной области. Работа выполнена
по теме №4 «Microwave circuits wave propagation».

Полный расчёт с объяснениями, графиками и выводами находится в
[выполненном ноутбуке](lab1_maxwell.ipynb).

## Уравнения

В однородной среде без потерь, при относительной магнитной проницаемости
$\mu_r=1$, вне источников выполняются уравнения

$$
\begin{aligned}
\frac{\partial\mathbf e}{\partial t}
&=\frac{c}{\varepsilon_r}\nabla\times\mathbf h, \\
\frac{\partial\mathbf h}{\partial t}
&=-c\nabla\times\mathbf e.
\end{aligned}
$$

Здесь $\mathbf e(x,y,z,t)$ и $\mathbf h(x,y,z,t)$ — нормированные электрическое
и магнитное поля, $c$ — скорость света в вакууме, а $\varepsilon_r$ — искомая
проницаемость. Нормировка имеет вид $\mathbf e=\sqrt{\varepsilon_0}\mathbf E$
и $\mathbf h=\sqrt{\mu_0}\mathbf H$, где E и H — поля в единицах SI.

## Постановка задачи

Даны значения двух полей во времени, известные источники возбуждения,
нулевое начальное состояние и периодические граничные условия.
Требуется найти **один постоянный параметр $\varepsilon_r\in[6,14]$**,
при котором рассчитанные поля лучше всего согласуются с данными.
Геометрия, сетка и остальные физические параметры фиксированы.

Для подбора используются первые четыре кадра траектории 0 из PDEArena.
Последние четыре кадра этой траектории и вся траектория 1 остаются для
проверки. Значение $\varepsilon_r=8$ используется для сравнения до подбора,
а известное значение 10 — для оценки точности восстановленного параметра.

## Метод

| Этап | Реализация |
|---|---|
| Символьная модель | Формулы задаются типизированным графом выражений; операции проверяются с помощью SymPy и SymEngine. |
| Хранение формулы | Граф сохраняется в словаре и матрице смежности с порядком аргументов и метаданными для восстановления. |
| Численное решение | Библиотека `fdtd` решает уравнения методом конечных разностей во времени FDTD по схеме Yee. Расчёт выполняется на CPU. |
| Устойчивость | Шаг времени выбирается по условию Куранта. Полная сетка PDEArena содержит 64³ узла, сравнивается сохранённая внутренняя область 32³. |
| Критерий подбора | Минимизируется среднее квадратов относительных L₂-ошибок электрического и магнитного полей. |
| Оптимизация | `scipy.optimize.minimize_scalar(method="bounded")` выбирает проницаемость в заданном интервале, вызывая солвер для каждого пробного значения. |
| Проверка точности | Ошибки оцениваются на отложенных данных и независимом точном решении при уточнении сетки. |

## Данные

Оба внешних набора содержат **синтетические данные численного моделирования**.
Экспериментальные измерения в работе не используются. Дополнительно
вычисляется точное аналитическое решение для независимой проверки солвера.

| Набор | Содержимое и назначение |
|---|---|
| [PDEArena Maxwell-3D](https://huggingface.co/datasets/pdearena/Maxwell-3D) | Используются две траектории, по восемь кадров полей e и h на сетке 32³. По ним выполняются восстановление проницаемости и проверка предсказаний. |
| [EMVal](https://huggingface.co/datasets/ArenaPhysica/EMVal) | Комплексные поля СВЧ-платы заданы в 10 000 пространственных точках. Выбраны один порт и частота около 10.5 ГГц. Данные используются для диагностики уравнений при известных свойствах материалов. |
| Аналитический эталон | Сумма трёх волн в периодическом кубе со стороной 3 см вычисляется по формуле. Она используется для проверки сходимости и отдельного контрольного подбора проницаемости. |

Происхождение данных, версии и лицензии описаны в
[sources/README.md](sources/README.md). Файлы автоматически загружаются
по [манифесту](sources/data_manifest.json) и проверяются по SHA-256.

## Результаты

| Проверка | Результат |
|---|---|
| Проницаемость по PDEArena | Найдено $\varepsilon_r\approx10.0000054$ при эталоне 10. |
| Ошибка электрического поля на поздних кадрах | Относительная L₂-ошибка составляет $1.55\cdot10^{-5}$, или около 0.00155%. |
| Ошибка электрического поля на второй траектории | Относительная L₂-ошибка составляет $1.33\cdot10^{-5}$. |
| Сходимость на аналитическом решении | При уменьшении пространственного и временного шагов вдвое ошибка уменьшается примерно в четыре раза. Наблюдается второй порядок сходимости. |
| Ошибка электрического поля на сетке 48³ | Относительная ошибка составляет около 0.12%. |
| Подбор по аналитическому решению | Найдено $\varepsilon_r\approx3.984$ при эталоне 4. Ошибка параметра составляет около 0.40%. |

Высокая точность на PDEArena связана с известными источниками и использованием
той же численной схемы, что и при генерации данных. Аналитический эталон
отдельно выявляет погрешность дискретизации.

На EMVal получены большие невязки уравнений. Точности локального восстановления
производных недостаточно для подтверждения модели платы этим способом.
Подбор параметров по EMVal не выполняется; ограничения диагностики разобраны
в ноутбуке.

## Запуск

Используется Python 3.13. Для работы достаточно CPU; первая загрузка данных
занимает около 412 МБ. Исходные массивы сохраняются локально и не входят в Git.

```bash
git clone https://github.com/gkarpeev/maxwell.git
cd maxwell
python3.13 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/run_notebook.py
```

Ноутбук выполняется в новом ядре и сохраняет все результаты. На использованном
CPU полный запуск занимает примерно минуту. Для интерактивного запуска
в Jupyter или VS Code нужно выбрать ядро `.venv` и выполнить
Restart Kernel → Run All.

Проверки кода запускаются командами:

```bash
.venv/bin/python -m pytest -q
.venv/bin/ruff check .
.venv/bin/ruff format --check .
```
