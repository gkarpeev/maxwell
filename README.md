# Лабораторная работа №1. Уравнения Максвелла

В работе по теме №4 «Microwave circuits wave propagation» по электрическому
и магнитному полям восстанавливается относительная диэлектрическая
проницаемость однородной трёхмерной среды. Подбирается только εᵣ;
остальные параметры, источники и начальные/граничные условия фиксированы.

**Основной документ — [выполненный ноутбук](lab1_maxwell.ipynb).** В нём
последовательно изложены постановка, уравнения и обозначения, источники
данных, символьная модель, численный метод, подбор параметра и выводы.
Каждый график сопровождается объяснением осей, обозначений и результатов.
Для просмотра сохранённых таблиц и рисунков запускать расчёт не требуется.

Для решения используется метод конечных разностей во времени FDTD
по схеме Yee из библиотеки `fdtd`. Оптимизатор SciPy минимизирует среднее
относительных квадратов ошибок электрического и магнитного полей.
Символьная часть сравнивает SymPy и SymEngine и сохраняет структуру
формул в графе, словаре и матрице с метаданными.

Данные PDEArena Maxwell-3D и EMVal синтетические: они получены численным
моделированием. На PDEArena выполняется подбор и проверка на отложенных
кадрах и второй траектории. Точное аналитическое решение используется
для независимой оценки сходимости. EMVal служит для диагностики полей
СВЧ-платы при известных свойствах материалов. Происхождение, закреплённые
версии и лицензии приведены в [описании источников](sources/README.md).

## Основные результаты

На PDEArena восстановлено εᵣ ≈ 10.0000054 при эталоне 10. Относительная
ошибка электрического поля на поздних кадрах составляет около 1.55·10⁻⁵,
а на второй траектории — около 1.33·10⁻⁵. Такое совпадение характеризует
задачу с известными источниками и той же дискретизацией, которая
использовалась при генерации данных.

На независимом аналитическом примере ошибки уменьшаются примерно
в четыре раза при уменьшении пространственного и временного шагов
вдвое. Ошибка электрического поля на сетке 48³ составляет около 0.12%,
а ошибка восстановления проницаемости по точному решению — около 0.40%.

На EMVal локальные оценки производных дают большие невязки. Эта
диагностика не подтверждает точность модели платы. Ограничения метода
и доступных метаданных рассмотрены в ноутбуке.

## Воспроизведение

Расчёты проверены на Python 3.13 и CPU. GPU и установка собственного
пакета не требуются. Для окружения и данных рекомендуется 1–2 ГБ
свободной оперативной памяти и диска. Первоначально скачивается около
412 МБ; файлы сохраняются локально и проверяются по SHA-256.
Исходные массивы в Git не включены.

```bash
python3.13 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/run_notebook.py
```

Последняя команда выполняет ноутбук с начала в новом ядре текущего
окружения и сохраняет результаты. Расчёт занимает примерно минуту
на использованном CPU; длительность зависит от оборудования.
Для интерактивной работы следует выбрать ядро `.venv` в Jupyter или
VS Code и выполнить Restart Kernel → Run All из папки проекта.

Автоматические проверки запускаются отдельно:

```bash
.venv/bin/python -m pytest -q
.venv/bin/ruff check .
.venv/bin/ruff format --check .
```

Вычислительные эксперименты без построения графиков можно выполнить
командой `.venv/bin/python experiments.py`.

## Организация кода

`symbolic_core.py` содержит типизированный граф выражений и преобразования
в SymPy, словарь и матрицу. `maxwell_symbolic.py` задаёт уравнения,
а `symbolic_comparison.py` сравнивает символьные библиотеки.

`maxwell_fdtd.py` воспроизводит постановку PDEArena с помощью `fdtd`.
`inference.py` хранит параметры и выполняет оптимизацию.
`analytic_benchmark.py` задаёт независимое точное решение,
а `emval_check.py` проверяет частотные поля платы.

`data_io.py` загружает данные по манифесту. `experiments.py` объединяет
вычисления, `visualization.py` строит рисунки, а `tests/` содержит
проверки символьного ядра и численных методов.

В `results/experiment.json` сохраняются метрики, история подбора,
диагностика и контрольные суммы кода. В этой же папке находятся граф
модели, матрица, их машинные представления и таблица сходимости.
